## FAQ

### What is in the Unreleased section?

Changes merged into the main branch for the upcoming 3.6.0 release. The pages mark them with a "Since 3.6.0" note, see [Versions of this documentation](/guide/versioning).

### What does [BC] mean?

A backward incompatible change. They appear only in major releases; the [upgrade guide](/upgrade) explains how to update your code.

### Which release does this documentation describe?

The 3.x line as of the unreleased 3.6.0; the latest release is 3.5.0 and lacks the "Since 3.6.0" features. See [Versions of this documentation](/guide/versioning).
