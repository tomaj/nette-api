## FAQ

### What is in the Unreleased section?

Changes merged into the main branch that are not in a release yet. When it is empty, the latest release has everything. Features added in a minor release are marked with a note such as "Since 3.6.0", see [Versions of this documentation](/guide/versioning).

### What does [BC] mean?

A backward incompatible change. They appear only in major releases; the [upgrade guide](/upgrade) explains how to update your code.

### Which release does this documentation describe?

The 3.x line, up to the latest release 3.6.0. See [Versions of this documentation](/guide/versioning).
