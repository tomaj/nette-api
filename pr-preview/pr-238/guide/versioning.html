Versions of this documentation ​

This site describes 3.x, the current release line; the latest release is 3.6.0. Install it with composer require tomaj/nette-api. It needs PHP 8.3 or newer. The master branch (dev-master) is 4.0 in development and needs PHP 8.4 or newer; its breaking changes are in UPGRADE-4.0.md.

LineWhere
3.xthis site, at the root
4.xwill take the root when it ships; 3.x moves to /3.x/
2.x and olderthe README of 2.13.0 on GitHub

The changelog lists every release, the upgrade guide the breaking changes.

FAQ ​

How do I know which version I have? ​

composer show tomaj/nette-api.

Will 3.x still get fixes after 4.0? ​

A 4.0.0 milestone is open with planned breaking changes, such as removing the unsafe 'auto' CORS mode and raising the minimum PHP version. It has no release date yet. Whether 3.x gets fixes after it is not decided; today fixes and features go to 3.x, and the changelog shows every release.

Do the pages mark features of a newer release? ​

Yes, a "Since 3.6.0" note marks what the 3.6.0 release added; older releases such as 3.5.0 do not have it, as on CORS and Logging.

Where do I report a mistake in the docs? ​

Open an issue or a pull request, see Contributing.

Is this the same as the API versions in my URLs? ​

No, those are described in Links and versions.
