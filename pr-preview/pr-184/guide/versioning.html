Versions of this documentation ​

This site describes 3.x, the current release line (3.5.0 at the time of writing). It needs PHP 8.3 or newer.

LineWhere
3.xthis site, at the root
4.xwill take the root when it ships; 3.x moves to /3.x/
2.x and olderthe README of 2.13.0 on GitHub

The changelog lists every release, the upgrade guide the breaking changes.

FAQ ​

How do I know which version I have? ​

composer show tomaj/nette-api.

Will 3.x still get fixes after 4.0? ​

The plan for 4.x is not announced yet. Today fixes and features go to 3.x; the changelog shows every release.

Do the pages mark features of a newer release? ​

Yes, a "Since 3.6.0" note marks what the latest 3.x release added, as on CORS and Logging.

Where do I report a mistake in the docs? ​

Open an issue or a pull request, see Contributing.

Is this the same as the API versions in my URLs? ​

No, those are described in Links and versions.
