FAQ ​

Which classes are final? ​

ApiPresenter, DefaultErrorHandler and the Latte extension classes are final; wrap them instead of extending. See Error handling.

Where are the method signatures? ​

In the source on GitHub; the guide pages show the ones you use.

Which classes are deprecated? ​

StaticBearerTokenRepository and BearerTokenRepositoryInterface. Use StaticTokenRepository and TokenRepositoryInterface, which work the same way.

Is there a DI extension? ​

No, everything is registered as plain services in NEON, see Getting started.

What does a full project look like? ​

See the examples.
