Nette APIRobustné REST API priamo vo vašej Nette aplikácii

Pridajte do Nette kompletnú API vrstvu: verzované endpointy, autorizáciu, validované parametre aj výstupy, CORS, rate limiting, logovanie a OpenAPI dokumentáciu – napojené cez Nette DI, jeden handler na endpoint.

Handlery namiesto presenterov

Každý endpoint je malá trieda s params(), outputs() a handle(). ApiDecider k nej priradí metódu, verziu a balík.

Validovaný vstup

GET, POST, PUT, cookie, súbor, raw a JSON telo s typmi, povolenými hodnotami a JSON schémami. Zlý vstup vráti 400.

Autorizácia a limity

Bearer tokeny, API kľúče v hlavičke, query alebo cookie, obmedzenie IP a vlastný rate limit pre každý endpoint.

OpenAPI a konzola

OpenApiHandler z handlerov vytvorí OpenAPI 3 dokument. ApiConsoleControl ponúkne formulár na vyskúšanie každého endpointu.

Ako to vyzerá ​

Handler je jedna trieda:

php
<?php

declare(strict_types=1);

namespace App\Api;

use Tomaj\NetteApi\Handlers\BaseHandler;
use Tomaj\NetteApi\Params\GetInputParam;
use Tomaj\NetteApi\Response\JsonApiResponse;
use Tomaj\NetteApi\Response\ResponseInterface;

final class HelloHandler extends BaseHandler
{
    public function summary(): string
    {
        return 'Say hello';
    }

    public function params(): array
    {
        return [
            (new GetInputParam('name'))->setDefault('world')->setDescription('Who to greet'),
        ];
    }

    public function handle(array $params): ResponseInterface
    {
        return new JsonApiResponse(200, ['message' => 'Hello ' . $params['name'] . '!']);
    }
}

a jeden riadok konfigurácie ho zaregistruje ako GET /api/v1/hello:

yaml
application:
    mapping:
        # Api:Api:default is Tomaj\NetteApi\Presenters\ApiPresenter
        Api: Tomaj\NetteApi\Presenters\*Presenter

services:
    router: App\RouterFactory::create

    # Nette 3.3 creates presenters only from the DI container
    - Tomaj\NetteApi\Presenters\ApiPresenter

    # required by ApiPresenter: when to validate output schemas and show error details
    - Tomaj\NetteApi\Output\Configurator\DebuggerConfigurator
    # required by ApiPresenter: turns errors into JSON responses
    - Tomaj\NetteApi\Error\DefaultErrorHandler

    apiDecider:
        factory: Tomaj\NetteApi\ApiDecider
        setup:
            # GET /api/v1/hello
            - addApi(
                Tomaj\NetteApi\EndpointIdentifier('GET', 1, 'hello'),
                App\Api\HelloHandler(),
                Tomaj\NetteApi\Authorization\NoAuthorization()
            )

Časté otázky ​

Čo je Nette API? ​

Knižnica, ktorá do Nette aplikácie pridá REST API vrstvu: endpointy, validované parametre aj výstupy, autorizáciu, CORS, rate limity, logovanie a OpenAPI dokument. Pozrite Začíname.

Ako zapadá do Nette aplikácie? ​

Cez jednu routu na jej ApiPresenter a služby zaregistrované v neon konfigurácii, takže handlery dostanú závislosti z Nette DI ako každá iná služba. Pozrite Začíname.

Aké verzie PHP a Nette potrebuje Nette API 3.x? ​

PHP 8.3 alebo novšie, nette/application a nette/http 3.x a Latte 3. Celý zoznam je v časti Začíname.

Musím pre endpointy písať presentery? ​

Nie. Knižnica má vlastný ApiPresenter a váš kód je v handleroch. Pozrite Handlery.

Ako fungujú verzie API? ​

Verzia je súčasťou každého endpointu, takže v1 a v2 tej istej URL môžu viesť na rôzne handlery. Pozrite Odkazy a verzie a príklad verzií.

Ako ochránim endpoint? ​

Pri registrácii mu dajte autorizáciu: bearer token, API kľúč v hlavičke, query alebo cookie, alebo vlastnú triedu. Pozrite Autorizáciu.

Spomalí to každú požiadavku? ​

Handlery zaregistrované názvom triedy sa vytvoria z DI kontajnera až pri volaní ich endpointu. Pozrite Architektúru.

Dá sa z kódu vygenerovať dokumentácia API? ​

Áno. Zaregistrujte OpenApiHandler a ten opíše každý endpoint ako OpenAPI 3.0, v JSON alebo YAML. Pozrite OpenAPI.

Je dokumentácia aj po anglicky? ​

Áno, každá stránka má anglickú verziu. Použite jazykové menu hore alebo začnite na anglickej úvodnej stránke.

Ako prejdem na 4.0? ​

Verzia 4.0 zatiaľ neexistuje; 3.x je aktuálna rada a plán pre 4.x nie je oznámený. Návod na upgrade pokrýva staršie hlavné verzie.
