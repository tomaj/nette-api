Začíname ​

Táto stránka vás prevedie od prázdnej Nette aplikácie k fungujúcemu endpointu GET /api/v1/hello. Hotový kód je príklad hello world.

Požiadavky ​

BalíkVerzia
PHP8.3 alebo novšie, s rozšíreniami curl, json, session a filter
nette/application, nette/http^3.0
latte/latte^3.0
tracy/tracy^2.6
justinrainbow/json-schema^5.2

1. Nainštalujte knižnicu ​

bash
composer require tomaj/nette-api

2. Nasmerujte API na ApiPresenter ​

Všetky endpointy idú do jedného presentera, Tomaj\NetteApi\Presenters\ApiPresenter. Namapujte modul Api na knižnicu a pridajte routu s parametrami version, package a voliteľným apiAction:

php
<?php

declare(strict_types=1);

namespace App;

use Nette\Application\Routers\RouteList;

final class RouterFactory
{
    public static function create(): RouteList
    {
        $router = new RouteList();
        // every API call goes to the presenter that ships with nette-api
        $router->addRoute('/api/v<version>/<package>[/<apiAction>][/<params>]', 'Api:Api:default');
        return $router;
    }
}

Presenter číta presne tieto tri parametre routy, preto ich názvy nemeňte.

3. Zaregistrujte služby ​

ApiPresenter potrebuje konfigurátor výstupu a error handler. ApiDecider drží zoznam endpointov:

yaml
application:
    mapping:
        # Api:Api:default is Tomaj\NetteApi\Presenters\ApiPresenter
        Api: Tomaj\NetteApi\Presenters\*Presenter

services:
    router: App\RouterFactory::create

    # Nette 3.3 creates presenters only from the DI container
    - Tomaj\NetteApi\Presenters\ApiPresenter

    # required by ApiPresenter: when to validate output schemas and show error details
    - Tomaj\NetteApi\Output\Configurator\DebuggerConfigurator
    # required by ApiPresenter: turns errors into JSON responses
    - Tomaj\NetteApi\Error\DefaultErrorHandler

    apiDecider:
        factory: Tomaj\NetteApi\ApiDecider
        setup:
            # GET /api/v1/hello
            - addApi(
                Tomaj\NetteApi\EndpointIdentifier('GET', 1, 'hello'),
                App\Api\HelloHandler(),
                Tomaj\NetteApi\Authorization\NoAuthorization()
            )

Nette 3.3 vytvára presentery len z DI kontajnera, preto je ApiPresenter uvedený aj ako služba.

4. Napíšte handler ​

php
<?php

declare(strict_types=1);

namespace App\Api;

use Tomaj\NetteApi\Handlers\BaseHandler;
use Tomaj\NetteApi\Params\GetInputParam;
use Tomaj\NetteApi\Response\JsonApiResponse;
use Tomaj\NetteApi\Response\ResponseInterface;

final class HelloHandler extends BaseHandler
{
    public function summary(): string
    {
        return 'Say hello';
    }

    public function params(): array
    {
        return [
            (new GetInputParam('name'))->setDefault('world')->setDescription('Who to greet'),
        ];
    }

    public function handle(array $params): ResponseInterface
    {
        return new JsonApiResponse(200, ['message' => 'Hello ' . $params['name'] . '!']);
    }
}

handle() dostane zvalidované parametre ako pole a vráti odpoveď. Ostatné metódy vysvetľujú Handlery.

5. Zavolajte ho ​

bash
curl http://localhost:8000/api/v1/hello?name=Nette
# {"message":"Hello Nette!"}

Endpoint, ktorý nie je zaregistrovaný, vráti 404 s {"status":"error","message":"Unknown api endpoint"}.

Časté otázky ​

Prečo môj endpoint vracia 404, hoci som ho zaregistroval? ​

Metóda, verzia, balík aj akcia sa musia zhodovať. GET a POST sú rôzne endpointy. Skontrolujte aj parametre routy; pozrite Architektúru.

Potrebujem pre každý endpoint vlastný presenter? ​

Nie, ApiPresenter obslúži všetky. Vy píšete handlery.

Môže byť verzia reťazec, napríklad 2.1? ​

Áno. EndpointIdentifier ukladá verziu ako reťazec, takže v2.1/users funguje. Pozrite Odkazy a verzie.

Ako pridám k endpointu autorizáciu? ​

Ako tretí argument addApi() odovzdajte iný objekt, napríklad BearerTokenAuthorization. Pozrite Autorizáciu.

Kde nájdem kompletný projekt, ktorý si môžem spustiť? ​

V examples/hello-world. Každý príklad má test e2e.sh, ktorý spúšťa CI.
