Handlery ​

Handler je kód jedného endpointu. Implementuje Tomaj\NetteApi\Handlers\ApiHandlerInterface; v praxi dedíte z BaseHandler a píšete handle().

Metódy ​

MetódaPredvolená hodnota v BaseHandlerPoužíva
handle(array $params): ResponseInterfaceabstraktná, píšete ju vyApiPresenter
params(): array[]validácia, OpenAPI, konzola
outputs(): array[]kontrola výstupu, OpenAPI
summary(): string''OpenAPI, konzola
description(): string''OpenAPI, konzola
tags(): array[]OpenAPI
deprecated(): boolfalseOpenAPI

handle() dostane hodnoty parametrov podľa ich názvov. Vracia odpoveď, napríklad JsonApiResponse, pozrite Výstupy a odpovede.

php
final class UserDetailHandler extends BaseHandler
{
    public function __construct(private UserRepository $users)
    {
        parent::__construct();
    }

    public function summary(): string
    {
        return 'Get one user';
    }

    public function params(): array
    {
        return [
            (new GetInputParam('id', InputType::INTEGER))->setRequired(),
        ];
    }

    public function handle(array $params): ResponseInterface
    {
        $user = $this->users->find($params['id']);
        if ($user === null) {
            return new JsonApiResponse(404, ['status' => 'error', 'message' => 'User not found']);
        }
        return new JsonApiResponse(200, ['user' => $user]);
    }
}

BaseHandler má konštruktor s voliteľným Fractal ScopeFactoryInterface. Keď má váš handler vlastný konštruktor, zavolajte parent::__construct().

Registrácia handlera ​

ApiDecider::addApi() berie endpoint, handler, autorizáciu a voliteľný rate limit:

yaml
services:
    - App\Api\UserDetailHandler
    apiDecider:
        factory: Tomaj\NetteApi\ApiDecider
        setup:
            - addApi(Tomaj\NetteApi\EndpointIdentifier('GET', 1, 'users', 'detail'), App\Api\UserDetailHandler, Tomaj\NetteApi\Authorization\NoAuthorization())

Handler môže byť objekt alebo názov triedy. Názov triedy sa hľadá v DI kontajneri až pri volaní endpointu, takže handler s ťažkými závislosťami nič nestojí pri iných požiadavkách. Zároveň to rieši cyklické závislosti, napríklad pre OpenApiHandler, ktorý potrebuje samotný ApiDecider.

Vlastný endpoint ​

ApiDecider zavolá setEndpointIdentifier() pred handle(), takže $this->getEndpoint() vráti nájdený endpoint. Príklad autorizácie vracia getEndpoint()->getUrl(), čo je pre tú routu v1/bearer/.

createLink() vytvorí absolútny odkaz na ten istý endpoint, keď predtým zavoláte setupLinkGenerator() s Nette LinkGenerator. Odkazy na iné endpointy opisujú Odkazy a verzie.

Handlery, ktoré sú súčasťou knižnice ​

TriedaČo robí
DefaultHandlerVráti 404 Unknown api endpoint, používa sa pre neznáme endpointy.
AlwaysOkHandlerVráti 200 {"status":"ok"}, hodí sa na health check.
EchoHandlerVráti povinný status (ok alebo error) a všetky svoje parametre, na testovanie.
CorsPreflightHandlerOdpovedá na OPTIONS požiadavky, pozrite CORS.

Časté otázky ​

Musia byť handlery služby? ​

Nie, addApi() prijme aj objekt vytvorený v neon setupe. Ako služby ich registrujte, keď potrebujú autowirované závislosti. Robí to príklad parametrov.

Ako vrátim iný stavový kód? ​

Odovzdajte ho ako prvý argument odpovede, napríklad new JsonApiResponse(404, [...]). Pozrite Výstupy a odpovede.

Mám v handle() zachytávať výnimky? ​

Len keď chcete konkrétnu odpoveď. Nezachytené výnimky idú do error handlera a stane sa z nich 500. Pozrite Spracovanie chýb.

Ako označím endpoint ako zastaraný? ​

Vráťte true z deprecated(). OpenAPI označí operáciu ako deprecated; endpoint funguje ďalej. Pozrite OpenAPI.

Môže jeden handler obsluhovať dva endpointy? ​

Áno, zaregistrujte ho dvakrát s rôznymi EndpointIdentifier. getEndpoint() povie, ktorý bol zavolaný. Pozrite Odkazy a verzie.
