Vrstvy ​

Požiadavka prejde pevnou sadou vrstiev. Každá má jednu úlohu a vlastné rozhranie, takže jednu vymeníte bez zásahu do ostatných. Handler, kde je vaša logika, vidí iba čisté hodnoty.

Presné poradie aj s kódom je na stránke Spracovanie v ApiPresenteri.

Routa ​

Jedna routa pošle každú URL API do presentera. Zástupné symboly sa stanú časťami endpointu.

php
$router->addRoute('/api/v<version>/<package>[/<apiAction>][/<params>]', 'Api:Api:default');

GET /api/v1/users/detail dá version 1, package users a apiAction detail. Pozrite Začíname.

ApiDecider: ktorý endpoint ​

ApiDecider drží zoznam endpointov. Každá položka spája EndpointIdentifier s handlerom, autorizáciou a voliteľným rate limitom:

yaml
- addApi(Tomaj\NetteApi\EndpointIdentifier('GET', 1, 'users', 'detail'), App\Api\UserDetailHandler, @bearer, @userLimit)

Kto smie volať a ako často teda patrí k endpointu, nie k handleru. Jeden handler môže byť pod jednou URL verejný a pod inou chránený. Pozrite ApiDecider a endpointy.

Rate limit: ako často ​

RateLimitInterface::check() vráti null pre žiadny limit, alebo RateLimitResponse s limitom a zvyškom. Pri 0 presenter odpovie 429. Beží pred autorizáciou, takže obmedzený je aj klient, ktorý hádá tokeny. Pozrite Obmedzenie počtu požiadaviek a príklad rate limitu.

Autorizácia: kto ​

ApiAuthorizationInterface má dve metódy:

php
public function authorized(): bool;
public function getErrorMessage(): ?string;

false odpovie 401 so správou. Súčasťou knižnice sú NoAuthorization, BearerTokenAuthorization, API kľúče v hlavičke, query a cookie a BasicAuthentication. Pre roly alebo session si napíšte vlastnú, ako v príklade vlastnej autorizácie. Pozrite Autorizácia.

Parametre: čo prišlo ​

params() handlera vymenuje vstupy. Každý parameter vie, odkiaľ čítať (query, POST, PUT, cookie, súbor, surové alebo JSON telo), či je povinný, jeho typ a povolené hodnoty:

php
public function params(): array
{
    return [
        (new GetInputParam('page', InputType::INTEGER))->setDefault(1),
        (new JsonInputParam('order', file_get_contents(__DIR__ . '/schema/order.json')))->setRequired(),
    ];
}

Presenter ich načíta všetky a chyby nahlási ako 400 so správou pre každý parameter. Handler neplatný vstup nikdy neuvidí. Pozrite Vstupné parametre.

Handler: vaša logika ​

Handler dostane $params s čistými hodnotami a vráti odpoveď. Neoveruje tokeny ani neparsuje požiadavku.

php
public function handle(array $params): ResponseInterface
{
    $user = $this->users->find($params['id']);
    if ($user === null) {
        return new JsonApiResponse(404, ['status' => 'error', 'message' => 'User not found']);
    }
    return new JsonApiResponse(200, ['id' => $user->id, 'name' => $user->name]);
}

summary(), description(), tags() a deprecated() popisujú endpoint pre OpenAPI. Pozrite Handlery.

Výstupy: čo odchádza ​

outputs() vymenuje povolené odpovede, každú s kódom a JSON schémou. Keď je validácia zapnutá, odpoveď musí zodpovedať aspoň jednej, inak klient dostane 500. Handler bez výstupov sa nekontroluje. Kedy kontrolovať, rozhodne konfigurátor, napríklad EnvConfigurator iba mimo produkcie. Pozrite Výstupy.

Logger: čo sa stalo ​

So službou ApiLoggerInterface v kontajneri sa zaloguje každá požiadavka, ktorá sa dostala k handleru, s kódom, metódou, hlavičkami, URI, IP, user agentom a časom. setMaskedLogHeaders() skryje tajné hlavičky. Pozrite Logovanie.

Časté otázky ​

Kam patrí biznis logika? ​

Do handlera alebo do služby, ktorú volá. Ostatné vrstvy iba rozhodujú, či sa spustí, a kontrolujú, čo vráti.

Môže handler prečítať autorizovaného používateľa? ​

Áno, cez zdieľanú službu, ktorú autorizácia naplní, ako CurrentUser v príklade vlastnej autorizácie.

Prečo sa parametre čítajú pred autorizáciou, ale hlásia po nej? ​

Aby autorizácia mohla použiť hodnoty, napríklad token v parametri, a volajúci bez prístupu aj tak dostal 401 a o parametroch sa nič nedozvedel.

Ktoré vrstvy môžem vynechať? ​

Rate limit, logger a výstupy sú voliteľné. Autorizácia je povinná pre každý endpoint; pre verejné použite NoAuthorization.

Ako otestujem jednu vrstvu? ​

Každá je obyčajný objekt: zavolajte priamo handle(), authorized(), ParamsProcessor alebo validate(). Pozrite príklad testovania.
