Vstupné parametre ​

params() vracia vstupy endpointu. ApiPresenter ich všetky načíta a zvaliduje pred spustením handle(), ktorý dostane hodnoty podľa názvu.

Triedy parametrov ​

TriedaČíta zPoznámky
GetInputParamquery stringpodporuje typy a setMulti()
PostInputParamtelo formulára, $_POSTpodporuje typy a setMulti()
PutInputParamform-encoded telo ľubovoľnej metódybez prevodu typu, typ sa ale kontroluje: INTEGER odmietne aj "12", použite STRING alebo žiadny typ
CookieInputParamcookiebez prevodu typu, typ sa ale kontroluje: INTEGER odmietne aj "12", použite STRING alebo žiadny typ
FileInputParamnahraný súbor, $_FILESsetMulti() pre viac súborov
RawInputParamcelé telo požiadavky ako reťazecsetMulti() vyhodí výnimku
JsonInputParamcelé telo požiadavky dekódované ako JSONpotrebuje JSON schému; setMulti() vyhodí výnimku

Druhý argument konštruktora prvých dvoch je typ, jedna z konštánt Tomaj\NetteApi\Validation\InputType:

php
new GetInputParam('limit', InputType::INTEGER);

Nastavenia ​

Všetky parametre majú spoločné fluent API:

MetódaÚčinok
setRequired()null alebo '' vráti Field is required.
setDefault($value)použije sa, keď vstup chýba
setAvailableValues([...])prejdú len tieto hodnoty, inak Field contains not available value(s). Pri asociatívnom poli sú hodnotami kľúče, hodnoty poľa sú popisky pre konzolu.
setMulti()očakáva pole, ?id[]=1&id[]=2; typy a povolené hodnoty platia pre každú položku
setDescription()zobrazí sa v OpenAPI a v konzole
addExample($name, $value) / setExample($value)zobrazí sa v OpenAPI a predvyplní v konzole

Typy ​

TypPrevod
INTEGER, DOUBLE, FLOATčíselné reťazce sa prevedú
BOOLEAN1, true (bez ohľadu na veľkosť písmen) sú true, všetko ostatné false
STRINGostane, ako je
ARRAYmusí byť pole

Hodnota, ktorá nie je číslo, sa zmení na null

V 3.x ?limit=abc s typom INTEGER nie je chyba: hodnota sa pred validáciou prevedie na null, takže voliteľný parameter prejde a povinný vráti Field is required. V handle() vždy počítajte s null. Testuje to príklad parametrov.

JSON telo ​

JsonInputParam berie JSON schému ako reťazec a voči nej validuje dekódované telo:

php
<?php

declare(strict_types=1);

namespace App\Api;

use App\UserRepository;
use Tomaj\NetteApi\Handlers\BaseHandler;
use Tomaj\NetteApi\Output\JsonOutput;
use Tomaj\NetteApi\Params\JsonInputParam;
use Tomaj\NetteApi\Response\JsonApiResponse;
use Tomaj\NetteApi\Response\ResponseInterface;

final class UserCreateHandler extends BaseHandler
{
    public function __construct(private UserRepository $users)
    {
        parent::__construct();
    }

    public function summary(): string
    {
        return 'Create a user';
    }

    public function tags(): array
    {
        return ['users'];
    }

    public function params(): array
    {
        return [
            // the whole request body, validated against a JSON schema
            (new JsonInputParam('user', (string) file_get_contents(__DIR__ . '/schema/user-create.json')))
                ->setRequired()
                ->addExample('Alice', ['name' => 'Alice', 'email' => 'alice@example.com']),
        ];
    }

    public function handle(array $params): ResponseInterface
    {
        $user = $this->users->add($params['user']['name'], $params['user']['email']);
        return new JsonApiResponse(201, ['user' => $user]);
    }

    public function outputs(): array
    {
        return [
            new JsonOutput(201, (string) file_get_contents(__DIR__ . '/schema/user.json'), 'The new user'),
        ];
    }
}

Pokazený JSON vráti 400 s hláškou parsera, chýbajúce povinné telo vráti missing data.

Odpoveď 400 ​

So zapnutými detailmi chýb (pozrite Spracovanie chýb) sú chyby vypísané pre každý parameter:

json
{"status":"error","message":"wrong input","detail":{"status":["Field contains not available value(s)"]}}

S vypnutými detailmi má odpoveď len status a message.

Časté otázky ​

Ako načítam JSON telo bez schémy? ​

Použite RawInputParam a dekódujte ho sami, alebo do JsonInputParam odovzdajte voľnú schému, napríklad {"type":"object"}.

Prečo je môj celočíselný parameter null namiesto 400? ​

Nečíselné hodnoty sa v 3.x menia na null, pozrite upozornenie vyššie. Označte parameter ako povinný alebo kontrolujte null.

Môže parameter prijať viac hodnôt? ​

Áno, setMulti() a potom pošlite name[]=a&name[]=b. Pozrite príklad parametrov.

Kde sa zobrazia príklady, ktoré pridám? ​

V OpenAPI dokumente a ako predvyplnené hodnoty vo webovej konzole.

Môže autorizácia čítať parametre? ​

Načítané hodnoty nie. authorized() nemá argumenty; hodnotu si prečítajte z HTTP požiadavky sami, ako to robí QueryApiKeyAuthentication. Parametre sa načítajú pred autorizáciou, ale dostane ich len error handler, pozrite Architektúru.
