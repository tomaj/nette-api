OpenAPI ​

OpenApiHandler je bežný handler, ktorý vracia OpenAPI 3.0 dokument všetkých endpointov s rovnakou verziou, ako má on sám. Registruje sa ako ktorýkoľvek endpoint.

yaml
application:
    mapping:
        Api: Tomaj\NetteApi\Presenters\*Presenter
        *: App\UI\*\**Presenter

latte:
    extensions:
        # the {apiLink} tag
        - Tomaj\NetteApi\Link\ApiLinkExtension

parameters:
    apiTokens:
        secret-token: '*'

services:
    router: App\RouterFactory::create
    - Tomaj\NetteApi\Presenters\ApiPresenter
    - App\UI\Console\ConsolePresenter
    - Tomaj\NetteApi\Output\Configurator\EnvConfigurator
    - Tomaj\NetteApi\Error\DefaultErrorHandler
    - Tomaj\NetteApi\Misc\IpDetector

    apiLink: Tomaj\NetteApi\Link\ApiLink
    # {apiLink} calls the filter of this name
    latte.latteFactory:
        setup:
            - addFilter(apiLink, [@apiLink, link])

    - App\Api\BookListHandler
    - App\Api\BookCreateHandler
    # the listing handlers need ApiDecider, so they are registered by class name below
    # and created only when their endpoint is called
    - Tomaj\NetteApi\Handlers\OpenApiHandler(initData: [info: [title: 'Bookshelf API', description: 'Example API documented with OpenAPI']])
    - Tomaj\NetteApi\Handlers\ApiListingHandler

    apiDecider:
        factory: Tomaj\NetteApi\ApiDecider
        setup:
            - addApi(Tomaj\NetteApi\EndpointIdentifier('GET', 1, 'books'), App\Api\BookListHandler, Tomaj\NetteApi\Authorization\NoAuthorization())
            - addApi(Tomaj\NetteApi\EndpointIdentifier('POST', 1, 'books'), App\Api\BookCreateHandler, Tomaj\NetteApi\Authorization\BearerTokenAuthorization(Tomaj\NetteApi\Misc\StaticTokenRepository(%apiTokens%)))
            # GET /api/v1/openapi, ?format=yaml with symfony/yaml installed
            - addApi(Tomaj\NetteApi\EndpointIdentifier('GET', 1, 'openapi'), Tomaj\NetteApi\Handlers\OpenApiHandler, Tomaj\NetteApi\Authorization\NoAuthorization())
            # GET /api/v1/endpoints, a short JSON list of the version 1 endpoints
            - addApi(Tomaj\NetteApi\EndpointIdentifier('GET', 1, 'endpoints'), Tomaj\NetteApi\Handlers\ApiListingHandler, Tomaj\NetteApi\Authorization\NoAuthorization())

OpenApiHandler potrebuje ApiDecider, ktorý zase drží handlery, preto ho v addApi() registrujte názvom triedy. Vytvorí sa až pri volaní jeho endpointu.

Čo sa dostane do dokumentu ​

ZDo
summary(), description(), tags(), deprecated()operácie
params()parameters a requestBody pre parametre tela, ako JSON a raw vstup
outputs()responses s JSON schémami
trieda autorizáciesecuritySchemes a security: Bearer, Basic alebo apiKey v query, hlavičke či cookie
parametre, autorizácia400, keď sú parametre, 401, ak nejde o NoAuthorization, a 500 vždy

Endpointy s vlastnou triedou autorizácie sú bez security.

Konštruktor ​

php
new OpenApiHandler(
    ApiDecider $apiDecider,
    ApiLink $apiLink,
    Nette\Http\Request $request,
    array $initData = [],        // zlúči sa do dokumentu, napr. info.title
    array $allowedEndpoints = [] // cesta => metódy na zahrnutie, * v ceste; prázdne znamená všetky
)

?format=yaml vráti YAML, keď je nainštalovaný symfony/yaml; inak je povolený len json.

Časté otázky ​

Ako zmením názov „Nette API"? ​

Odovzdajte initData: [info: [title: 'My API']]. Rekurzívne sa zlúči s vygenerovaným dokumentom.

Môžem skryť interné endpointy? ​

Áno, verejné vymenujte v allowedEndpoints, alebo zaregistrujte druhý OpenApiHandler pre inú verziu.

Prečo chýbajú endpointy verzie 2? ​

Dokument pokrýva len verziu endpointu OpenApiHandler. Zaregistrujte jeden pre každú verziu; pozrite Odkazy a verzie.

Môžem dokument použiť so Swagger UI? ​

Áno, nasmerujte Swagger UI na URL endpointu. Knižnica má aj vlastnú webovú konzolu.

Je OpenAPI endpoint verejný? ​

Len ak ho zaregistrujete s NoAuthorization, ako to robí príklad OpenAPI. Funguje akákoľvek autorizácia.
